# Audit: Compose curriculum, 2026-10-06

**Scope:** the Dojo's intent, spec and plan; its GitHub issues; the nightly
live acceptance workflow (#55); and the parent suite plan and spec in
uFawkes.dev. **Method:** read all of them, then checked each claim against
the repos, release tags, workflow runs and the suite's own AC-DOJO-01 script.
Nothing here is from memory of earlier sessions.

## Verdict

1. **The foundations are solid.** The authoring guide (items 1–17), the PR
   template, the nightly (#55), the Module 0 "Start here" lab and the
   Module 2 lab-01 re-run all hold up, and were run for real.
2. **The plan's central rule was broken on 2026-10-05.** Twelve labs were
   written for stacks that had no release, in direct commits, with no run
   evidence, and eight of them name release tags that do not exist.
3. **Dojo 0.2 is not at its gate.** The suite's own AC-DOJO-01 check fails
   with 24 lines. An earlier statement that the accuracy pass was complete
   was wrong: it was checked with a narrower grep than the suite uses.

## Findings, ranked

### F1. Twelve labs were written ahead of their stacks, with no run evidence (critical)

The spec says "No module changes until the stack it targets is released, and
every lab step is run for real first" (R1, R2). On 2026-10-05, 24 of the 33
commits since 2026-10-04 landed directly on `main`, including these labs. Issues #42–#53 were all closed on 2026-10-05; for
example the Module 5 commit says `Closes #46`.

| Lab | Names | Tag exists? | In nightly? | Run evidence? |
|---|---|---|---|---|
| White 1 / 3 / 4 | uFawkesDevX `v1.0.1` | yes | no | none in lab or PR (#69–#71 describe checks only) |
| Yellow 5 / 6 / 7 / 8 | uFawkesPipe `v2.0.0` | **no** (newest is `v1.11.1-beta.1`) | no | none |
| Brown 13 / 14 | uFawkesObs `v1.0.0` | **no** (newest is `v1.0.6-rc.1`) | yes, against Obs `main` | `validate.sh` only; instructions stale (#72) |
| Brown 15 / 16 | uFawkesObs `v1.0.0` | **no** | no | none |

Also: no lab carries the provenance header or Verification Strategy mapping
that `dojo-handoff.md` (AC-DOJO-04) asks for. Eight labs name a release
tag that does not exist. The risk the parent plan lists, "free models produce
plausible but wrong content (especially curriculum)", is what this looks like.

### F2. AC-DOJO-01 fails the suite's own check (24 lines)

`uFawkes.dev/scripts/checks/ac-dojo-01.sh` scans the whole repo and passes a
line only if the same line says why it is historical.
The retired terms are Jenkins, the old four-metric claim, and video placeholders.
The 24 lines (the alignment PR for this audit fixes two of them, in
`INTENT.md` and the compose-curriculum intent, leaving 22):

- **Vision doc** (6): `Fawkes Dojo: Immersive Learning Architecture.md` still
  teaches the retired Jenkins pipelines and the old four-metric model.
- **Quiz distractors and comparisons** (9): retired `Jenkinsfile` options in Modules
  5, 6, 8 and the white assessment, plus two comparison lines.
- **Meta lines whose qualifier is on the next line or missing** (7): PR
  template, authoring guide (2), compose-curriculum intent, white-belt
  Module 2 README, `INTENT.md` (line-wrapped "not Jenkins"), the Four Keys
  project link.
- **Stale site and config** (2+): `index.html` says Module 5 "teaches Jenkins
  today", but Module 5 is already a uFawkesPipe module; `.pre-commit-config.yaml`
  excludes a `jenkins-shared-library/` path that does not exist here.

### F3. The nightly proves less than its name suggests

- It checks out uFawkesObs and uFawkesAI at the **default branch**
  (`_lab-acceptance.yml`: "the ref the labs clone"). That was true when labs
  cloned `main`. Labs now pin tags, so the nightly tests a different ref
  from the one a learner uses, and can pass while the declared pin is a dead
  link (Brown 13 / 14).
- It runs `validate.sh` only. It does not run the instructions' own steps, so
  it cannot see the rot in #72 (where the check passes and the taught flow
  fails). Module 2 lab-01 had several wrong steps while the nightly was green.
- It covers 4 of 14 labs. `uFawkes.dev/.../live-checks.yml` describes it as
  "runs every lab's validate.sh for real", which overstates it.
- It has one scheduled run so far, so there is no flake history yet.

### F4. Nothing stops an unverified lab reaching `main`

`main` had a ruleset (created 2026-10-03) that blocked deletion and force-pushes
but required no pull request and no status check, so direct pushes were allowed.
There was no CODEOWNERS. (An earlier version of this audit said "not protected";
it had checked only the classic branch-protection API, which does not see
rulesets.) Issues #42–#53 are
closed, so the tracker now reads "done" for content nobody ran. A closing keyword also closed #37 on 2026-10-06 by accident.

### F5. The Dojo's own documents disagree with each other and with reality

- `INTENT.md`: the Direction block is duplicated (commit `37bd322` spliced a
  new one above the old). It says "two runnable labs" (there are 14) and
  "Modules 3–4 remain Kubernetes-based" (migrated).
- `plan.md`: still "Revision 2" while the spec is revision 5. Two phases carry
  paragraphs of migration narrative that read as fact ("migrated to
  uFawkesObs v1.0.0"), cite PR numbers that are wrong (Modules 5–7 are
  attributed to #71, which is White Belt Module 4), and break the rule that
  the plan lists no task status.
- `index.html` and the README labs list are behind in the same way.

### F6. The parent plan has drifted too

- Phase 5 says uFawkesDevX ships `v0.1.0` (beta) after an ADR (#57, still
  open). DevX already has stable `v1.0.0` and `v1.0.1`. The Dojo plan and spec
  repeat "after v0.1.0".
- `acceptance.yml` lists AC-DOJO-02, -03 and -04 as manual with no evidence,
  and AC-DOJO-01 as a command, which now fails.
- AC-DOJO-04 ("each lab built from its stack's release plan, shipped the same
  week") cannot hold for labs written before the stack releases.

### F7. Smaller items

- Module 2 lab-02 clones uFawkesAI unpinned (spec AC-003).
- Module 2 lab-01's tour has no seed data to study (the stack has none), so
  it is not a populated worked example.
- Obs #534 (dead uFawkesRes panels) is still open and shows on the lab's
  dashboard.
