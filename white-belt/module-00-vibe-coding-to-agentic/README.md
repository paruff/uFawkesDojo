# White Belt Module 0: From Vibe Coding to Agentic Engineering

**Duration**: 10 minutes theory + "Start here" lab
**Prerequisites**: None — this is the Dojo entry point
**Runs against**: uFawkesAI `v2.0.0` (template + devcontainer)

---

## Overview

This primer introduces the **AI-Native SDLC mindset** that underpins the entire uFawkes Dojo curriculum. It cites *The AI-Native SDLC Playbook* (Claxton, Anthropic, 2026) and establishes the distinction between **vibe coding** (ad-hoc, unverified) and **agentic engineering** (structured, measurable, platform-enabled).

## Learning Path

1. **Read the primer** → `../modules/white-belt/module-00-vibe-coding-to-agentic.md` (10 min)
2. **Run the "Start here" lab** → [Lab 01](lab-01/instructions.md) (clones a pinned uFawkesAI template, opens its devcontainer, tours the six harness components, writes one intent→spec→plan chain; `validate.sh` checks it)
